
Simplicity is a GUI tool i made that helps changing a wallpaper without having to access Bash which some people including myself dont wont to. It also offers features like Setting up the 
FPS and Volume via Sliders and also Crash handling where if a wallpaper crashes due to its particle system often times, it loads again the wallpaper without its particles insteadd of stoping

The reason behind the app as i mentioned above is because i dont feel confortable using the bash all the time  and typing stuff, i wanted something quicker and more user friendly for 
myself first as a personal project which would help on somethign small like this and then i decided to make the repo public just in case anyone else had the same need.
