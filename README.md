
Simplicity is a GUI tool i made for the wallpaper engine plug in for KDE Linux DE'S that helps changing a wallpaper without having to access Bash which some people including myself don't want to. It also offers features like Setting up the 
- FPS and Volume via Sliders and also
- Crash handling where if a wallpaper crashes due to its particle system often times, it loads again the wallpaper without its particles instead of crashing and stopping thus making the preffred wallpaper incompatible and unusable.

The reason behind the app as i mentioned above is that i didn't felt comfortable using the bash all the time and typing stuff just to set up a plug in and a wallpaper, i wanted something familiar to me, quicker (at least for me who does not like working on bash) and a more user friendly experience for myself first as a personal project which would help on solving a small "problem" like this and then i decided to make the repo public just in case anyone else had the same need.
